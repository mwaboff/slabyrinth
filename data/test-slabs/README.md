# In-game proof slabs (WP3)

Generated by `npx tsx packages/core/scripts/make-test-slabs.ts` through the real pipeline: WP1 `validatePlan` → WP2 `resolvePlan` → WP3 realize / chunk / encode. The plans used are next to the slabs (`*.plan.json`); `manifest.json` lists sizes and diagnostics.

Directions below are compass directions with the camera facing **north** (north = up the screen, east = right). Every `.txt` file holds one bare base64 slab: open it, copy the whole line, then in TaleSpire build mode press **Ctrl+V** and hold left-click briefly to place it. Use an empty board.

**Default since 2026-11-18: as few slabs as possible.** A build is one slab whenever it fits, all levels included. It is split only when it does not fit, and then whole levels go into a chunk before any level is cut.

**Facing rule since 2026-11-18:** at rotation 0 a prop's front faces **north (+z)**. This is verified for the chair, Bookshelf 01 and Red Bed, and is the default for every other prop; per-asset palette overrides apply only where an asset is verified to differ.
